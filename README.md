You can install Instablocker here: https://addons.mozilla.org/en-GB/firefox/addon/instablock-for-x-twitter/

Instablock adds a block button next to the ••• menu on every post on X / Twitter. One click blocks the author straight away, with no menu to open and no "Are you sure?" dialog.

It works everywhere posts appear: your home timeline, search, profiles, replies, and posts you've opened in full.

Quote posts get two buttons: one for the person quoting, and a second inside the quoted post for its original author. You can block either one without opening the quoted post.

Clicked by mistake? Click the button again to unblock. Buttons for the same account turn red everywhere on the page once they're blocked.

Privacy: Instablock collects no data and has no settings, tracking or analytics. It only runs on x.com and twitter.com, and it only sends a request to X when you click a block button, using the same session you're already logged in with.
